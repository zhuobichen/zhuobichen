## 与月相对

我喜欢古诗，也喜欢文学里那种把有限人生放进无垠天地的目光。

所以我写代码时，总想让它不只是“能运行”：它应当像一盏灯，照见问题的纹理；也像一叶小舟，把复杂的工作流渡到更远的地方。

我的两条工作线，一条在 **AI 工程** 中寻找新的工具形态，一条在 **大气环境研究** 中辨认风、云与数据背后的真实信号。它们看似相隔很远，却都在回答同一个问题：如何从纷繁世界里，留下可靠而有用的东西。
