## 考公备考档案

- **个人背景**：广西钦州人，华南理工大学资源与环境专业硕士。
- **备考目标**：以广西区考、国家公务员考试为主，广西全区均可报考；地域优先级为钦州、南宁、广西其他地市，同时关注广西区直及国考广西岗位。
- **专业方向**：生态环境、自然资源、海洋、林业、水利、农业农村、住建等相关岗位；具体资格以当年职位表和专业目录为准。
- **复习方式**：利用零散时间，从零基础开始，采用“真题诊断—模块训练—错题复盘—间隔记忆”的循环。
- **学习特征**：自学能力和目标驱动能力较强；曾在基本不看课程的情况下独立复习华南理工大学资源与环境硕士研究生入学考试，并取得 400+ 分。备考应优先采用自学、真题和反馈驱动的框架，课程仅用于解决具体卡点。
- **关注资料**：广西人事考试网、国家公务员局等官方公告；GitHub 上使用 AnkiDroid、civil-service-exam、coder2gwy 等项目辅助学习。
- **资料原则**：优先使用当年官方信息和正规出版物，谨慎对待过期资料、AI 评分及来源不明的题库。

### 微信公众号建议

- **官方信息**：国家公务员局、广西人事考试网（以认证主体和当年公告为准）。
- **时政与申论素材**：半月谈、人民日报、学习大国。每天选一篇精读即可，不追求全部浏览。
- **课程与真题**：粉笔职教、中公教育、华图在线。三家选一家作为主线，避免重复购买和混用方法。

### 书籍建议

1. 粉笔《行测的思维》：适合零基础建立五大模块的方法框架。
2. 粉笔《申论的规矩》：适合先理解申论题型、答案结构和作答规范。
3. 最新版国考、广西区考《历年真题》：优先买分模块解析详细、带答题卡的版本。
4. 《半月谈》或同类时政资料：用于积累申论案例和政策表达，不必背整本。

购买时选择 **2027 年国考/广西区考最新版本**，并把真题放在课程之前使用；先做诊断，再决定补哪些模块。
