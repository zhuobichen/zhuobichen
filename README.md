## 我的工作台

我在两条轨道上写代码：一条把复杂的 AI 工作流变成可靠工具，另一条把观测、模拟和研究问题连接成可复现的数据流程。

| 月 | 时 | 气 |
|:---:|:---:|:---:|
| 观察问题，也观察技术的变化 | 把长期研究拆成可验证的步骤 | 从空气质量数据中寻找真实世界的信号 |
| `ideas → systems` | `methods → evidence` | `observations → impact` |

```text
AI tools ──→ agents ──→ MCP ──→ local workflows
observations ──→ fusion ──→ WRF-CMAQ ──→ health impact
```

## 正在构建

### 01 · AI 工具轨道

- **[weflow-cli](https://github.com/zhuobichen/weflow-cli)**：本地优先的微信数据工具，连接聊天记录、日报、知识库与 MCP。
- **[dsh-team](https://github.com/zhuobichen/dsh-team)**：让多个 Agent 以顺序接力或 DAG 图协作完成复杂任务。
- **[pilgrim-intel](https://github.com/zhuobichen/pilgrim-intel)**：把分散的信息源整理成可查询、可追踪的 AI 情报流。
- **[lingtai-reader](https://github.com/zhuobichen/lingtai-reader)**：在本地完成阅读、笔记和 AI 辅助，不把私人内容交给远端。

### 02 · 大气研究轨道

- **[PM25-Fusion-AutoResearch](https://github.com/zhuobichen/PM25-Fusion-AutoResearch)**：PM2.5 监测-模型数据融合自动研究框架。
- **[DataFusion_China_CleanAir](https://github.com/zhuobichen/DataFusion_China_CleanAir)**：中国区域空气质量数据融合与健康效益评估。
- **[FusionMethods](https://github.com/zhuobichen/FusionMethods)**：VNA / eVNA / aVNA / Downscaler 等方法的复现与验证。
- **[guangdong-wrf-cmaq](https://github.com/zhuobichen/guangdong-wrf-cmaq)**：广东省 WRF-CMAQ 空气质量多尺度模拟与评估。
